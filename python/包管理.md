## 路线 A：pyenv（最成熟，教程最多）

### 1. 安装 pyenv

Apple Silicon（M1/M2/M3）：

```bash
brew install pyenv
```

Intel Mac：

```bash
brew install pyenv
```

一样的命令，Homebrew 会自动处理架构差异。

### 2. 配置 shell 环境

pyenv 的原理是在 PATH 最前面插入一层 shim，拦截 `python` 命令并转发到你指定的版本。

把这段加到 `~/.zshrc` 末尾：

```bash
export PYENV_ROOT="$HOME/.pyenv"
[[ -d $PYENV_ROOT/bin ]] && export PATH="$PYENV_ROOT/bin:$PATH"
eval "$(pyenv init -)"
```

然后生效：

```bash
source ~/.zshrc
```

验证一下：

```bash
pyenv --version
```

### 3. 安装 Python（重点：编译依赖）

macOS 上 pyenv 是从源码编译 Python 的，需要先装 Xcode 命令行工具：

```bash
xcode-select --install
```

如果你用 Homebrew 装过 openssl/readline，pyenv 也能自动捡到。保险起见跑一下：

```bash
brew install openssl readline sqlite3 xz zlib tcl-tk
```

然后安装你想要的 Python 版本，比如 3.12：

```bash
pyenv install 3.12.4
```

这个过程要几分钟，在编译 C 代码。看到 `Installed Python-3.12.4` 就成功了。

查看已安装的版本：

```bash
pyenv versions
```

### 4. 设置全局默认 python

```bash
pyenv global 3.12.4
```

现在试试：

```bash
which python    # 应该指向 ~/.pyenv/shims/python
python -V       # Python 3.12.4
python3 -V      # 同一个
```

✅ 到这里，`python` 命令就有了，而且指向的是你管理的版本，和系统自带的完全解耦。

### 5. VS Code 里配置

1. 

   `Cmd+Shift+P` → `Python: Select Interpreter`

2. 

   选那个带 `(pyenv)` 标注的，路径类似 `~/.pyenv/versions/3.12.4/bin/python`

3. 

   集成终端里 `python -V` 应该直接生效

### 6. 项目级隔离（这才是 pyenv 的真正价值）

进到一个项目目录：

```bash
cd my-project
pyenv local 3.11.9   # 创建 .python-version 文件
```

以后进这个目录自动切到 3.11.9，出目录回到 global。配合 venv：

```bash
python -m venv .venv
source .venv/bin/activate
```

## 路线 B：uv（强烈推荐新项目用）

uv 是 Astral 公司做的（就是搞 ruff 的那帮人），Rust 写的，比 pip 快 10~100 倍，内置 Python 版本管理，不需要 pyenv。

### 1. 安装 uv

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

装完会提示把 `~/.local/bin` 加入 PATH。如果你用的是 zsh，它会自动改 `~/.zshrc`。没改的话手动加：

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

验证：

```bash
uv --version
```

### 2. 安装并设置默认 Python

```bash
uv python install 3.12
uv python pin 3.12   # 设为默认
```

看看：

```bash
which python    # ~/.local/bin/python
python -V       # Python 3.12.x
```

uv 下载的是预编译二进制，不是从源码编译，所以**30 秒搞定**，不像 pyenv 要编译好几分钟。

### 3. 创建项目（uv 的杀手功能）

```bash
mkdir my-project && cd my-project
uv init          # 初始化 pyproject.toml
uv add requests  # 装包，飞快
uv run main.py   # 用项目隔离环境运行
```

uv 会在项目目录下创建一个 `.venv`，自动管理依赖锁文件 `uv.lock`。你甚至不需要手动 `source .venv/bin/activate`，`uv run` 自动帮你激活。

### 4. VS Code 里配置

```
Cmd+Shift+P` → `Python: Select Interpreter` → 选 `.venv/bin/python
```

或者让 VS Code 自动检测，uv 创建的项目 VS Code Python 插件基本都能识别。

## pyenv vs uv 怎么选？



|          | pyenv                | uv                          |
| -------- | -------------------- | --------------------------- |
| 学习成本 | 低，概念简单         | 低，但生态新                |
| 安装速度 | 慢（源码编译）       | 极快（预编译）              |
| 包管理   | 需要 pip/venv/poetry | 内置，一站式                |
| 成熟度   | 10 年+，非常稳       | 2024 年才火，但背后公司靠谱 |
| 适合人群 | 习惯了传统工作流的人 | 新项目、追求效率的人        |
