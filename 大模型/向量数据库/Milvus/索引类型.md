## milvus索引类型

## 浮点 / 稠密向量（FLOAT_VECTOR、FLOAT16_VECTOR、BFLOAT16_VECTOR、INT8_VECTOR）



**IVF = Inverted File Index（倒排文件索引）**，是一种基于**聚类（k-means）的近似最近邻（ANN）索引**。核心思路是：建索引时把向量空间切成很多个簇（cluster），查的时候不扫全库，只扫离查询向量最近的几个簇。





- **FLAT**：暴力精确检索，100% 召回，慢，适合百万级以下或做 baseline
- **IVF 系列（量化聚类）**
  - `IVF_FLAT`：不压缩向量，召回高，内存占用大
  - `IVF_SQ8`：标量量化压缩，省内存，召回略降
  - `IVF_PQ`：乘积量化，内存极低，召回损失较大
  - `IVF_RABITQ`：新一代量化方案，兼顾压缩与召回
- **HNSW 系列（图索引）**
  - `HNSW`：内存图索引，低延迟高召回，吃内存
  - `HNSW_SQ` / `HNSW_PQ` / `HNSW_PRQ`：在 HNSW 上叠加 SQ/PQ/PRQ 量化，换内存
- **DISKANN**：磁盘驻留图索引，适合超内存规模（十亿级）
- **SCANN**：Google 系量化+重排，CPU 高性能
- **AISAQ**：近似量化倒排，新兴索引
- **GPU 专用**
  - `GPU_CAGRA`：GPU 图索引，高吞吐
  - `GPU_IVF_FLAT` / `GPU_IVF_PQ`：GPU 版 IVF
  - `GPU_BRUTE_FORCE`：GPU 暴力精确

## 二进制向量（BINARY_VECTOR）

- `BIN_FLAT`：二进制暴力检索
- `BIN_IVF_FLAT`：二进制 IVF
- `MINHASH_LSH`：MinHash + LSH，面向 Jaccard 相似

## 稀疏向量（SPARSE_FLOAT_VECTOR）

- `SPARSE_INVERTED_INDEX`：稀疏倒排（支持 `IP` / `BM25`，可配 `DAAT_WAND` 等算法，原 `SPARSE_WAND` 已废弃）

## 标量字段索引

- `INVERTED`：字符串 / 数值通用倒排，高基数字段推荐
- `BITMAP`：BOOL、低基数 INT、ARRAY 元素过滤推荐
- `Trie`：VARCHAR 前缀类查询
- `STL_SORT`：数值范围查询（int 系）
- JSON / ARRAY 字段：通常用 `INVERTED`（ARRAY 元素也可 `BITMAP`）

## 自动索引

- `AUTOINDEX`：不手写类型时由 Milvus 按数据/硬件挑合适索引，原型开发首选 

#### 内存类型选择

- 小数据 + 要绝对准 → FLAT
- 内存够 + 要快且准 → HNSW
- 内存紧 → IVF_SQ8 / IVF_PQ / HNSW_SQ
- 数据放不下内存 → DISKANN
- 有 GPU 要吞吐 → GPU_CAGRA / GPU_IVF_PQ
- 稀疏 BM25 文本 → SPARSE_INVERTED_INDEX
- 不想选 → AUTOINDEX







**IVF和HNSW创建索引demo**

```
from pymilvus import (
    connections,
    Collection,
    FieldSchema,
    CollectionSchema,
    DataType,
    utility
)

connections.connect(alias="default", host="localhost", port="19530")

# ===== 公共部分：建集合 =====
fields = [
    FieldSchema(name="id", dtype=DataType.INT64, is_primary=True),
    FieldSchema(name="embedding", dtype=DataType.FLOAT_VECTOR, dim=128),
    FieldSchema(name="category", dtype=DataType.VARCHAR, max_length=50),
]
schema = CollectionSchema(fields, description="demo collection")
collection = Collection(name="ann_demo", schema=schema)

# 灌数据（示意）
import random
data = [
    [i for i in range(100000)],
    [[random.random() for _ in range(128)] for _ in range(100000)],
    [f"cat_{i % 10}" for i in range(100000)],
]
collection.insert(data)


# ============================================
# 左边：IVF_FLAT     |     右边：HNSW
# ============================================

# ---------- IVF_FLAT ----------
ivf_index = {
    "index_type": "IVF_FLAT",
    "metric_type": "L2",        # 可选 IP / L2
    "params": {
        "nlist": 1024,           # 簇数量，建索引时定
    },
}
collection.create_index(
    field_name="embedding",
    index_params=ivf_index
)

# ---------- HNSW ----------
hnsw_index = {
    "index_type": "HNSW",
    "metric_type": "L2",        # 可选 IP / L2
    "params": {
        "M": 16,                 # 每个节点的边数，建索引时定
        "efConstruction": 256,   # 建索引时候选队列大小，建索引时定
    },
}
collection.create_index(
    field_name="embedding",
    index_params=hnsw_index
)


# ============================================
# 加载 + 搜索（参数差异在这里）
# ============================================
collection.load()

search_vec = [[random.random() for _ in range(128)]]

# ---------- IVF_FLAT 搜索 ----------
search_params_ivf = {
    "metric_type": "L2",
    "params": {
        "nprobe": 16,            # ★ 可调，越大越准越慢
    }
}
results_ivf = collection.search(
    data=search_vec,
    anns_field="embedding",
    param=search_params_ivf,
    limit=10,
    expr='category == "cat_1"',  # 标量过滤示例
    output_fields=["id"]
)

# ---------- HNSW 搜索 ----------
search_params_hnsw = {
    "metric_type": "L2",
    "params": {
        "ef": 128,               # ★ 可调，等价于 IVF 的 nprobe
    }
}
results_hnsw = collection.search(
    data=search_vec,
    anns_field="embedding",
    param=search_params_hnsw,
    limit=10,
    expr='category == "cat_1"',
    output_fields=["id"]
)
```
