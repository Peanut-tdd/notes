## VSCode 替换相关快捷键

| 操作               | macOS              | Windows / Linux    |
| ------------------ | ------------------ | ------------------ |
| 当前文件查找并替换 | `Cmd + Option + F` | `Ctrl + H`         |
| 跨文件查找并替换   | `Cmd + Shift + H`  | `Ctrl +Shift + H`  |
| 查找（不含替换）   | `Cmd + F`          | `Ctrl + F`         |
| 跨文件查找         | `Cmd + Shift + F`  | `Ctrl + Shift + F` |





注释快捷键

 - 单行注释切换：Cmd + /（macOS）/ Ctrl + /（Windows/Linux）                                                           
 - 多行块注释：Option + Shift + A（macOS）/ Alt + Shift + A（Windows/Linux）
