### pprof 新能分析



http方式查看

```
import (
	"net/http"
	_ "net/http/pprof"
)


//开放6060端口
func main() {

	go func() {
		http.ListenAndServe("localhost:6060", nil)
	}()
	
	
	select {}
}

```







#### cpu使用分析

```
go tool pprof "http://localhost:6060/debug/pprof/profile?seconds=30"
```



top:函数耗时排名

top -cum :累计耗时排名   flat ≈ cum → 真干活，cum ≫ flat → 在等锁 / IO / channel

list 函数名：具体耗时的地方

web：页面查看



http转发web查看

```
go tool pprof -http=:6061 "http://localhost:6060/debug/pprof/heap"
```



#### heap使用分析

```
go tool pprof "http://localhost:6060/debug/pprof/heap"
```

top10 -inuse_space :正在使用的内存占用

top10 -alloc_space :已分配内存情况



注：性能分析看-alloc_space,内存泄漏看-inuse_space





#### goroutine使用分析

```
go tool pprof "http://localhost:6060/debug/pprof/goroutine"
```



Top10 : flat 看协程数，cum gopark协程挂起百分比

```
curl "http://localhost:6060/debug/pprof/goroutine?debug=1" 看协程数

curl "http://localhost:6060/denig/pprof/goroutine?debug=2" 看执行栈，如chan.recv
```















#### k8s 采集并分析pporf

```
# 方法一：通过kubectl exec直接在容器内采集
kubectl exec -it <pod-name> -- go tool pprof -http=:8080 http://127.0.0.1:6060/debug/pprof/profile?seconds=30

# 方法二：先端口转发，再在本地分析
kubectl port-forward pod/<pod-name> 6060:6060
# 在本地终端执行，会自动打开浏览器
go tool pprof -http=:8080 http://127.0.0.1:6060/debug/pprof/profile?seconds=30
```
